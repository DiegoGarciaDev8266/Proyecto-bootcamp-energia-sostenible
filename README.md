# Energía Hidroeléctrica: un viaje hacia la sostenibilidad

Proyecto del bootcamp **Talento Tech** (La Dorada, Caldas), noviembre–diciembre de 2024. Equipo "Masters".

## Descripción
Sitio web educativo sobre la transición energética sostenible, con énfasis en la energía hidroeléctrica. Permite visualizar datos históricos de producción y consumo de energía renovable y calcular el porcentaje de energía renovable a partir del consumo eléctrico.

## Funcionalidades
- Dashboard interactivo con gráficos de barras, torta, líneas y área.
- Calculadora del porcentaje de energía renovable (consumo en kWh).
- Formulario de sugerencias para recibir retroalimentación.
- Diseño responsivo.

## Tecnologías
HTML5, CSS3, JavaScript, Bootstrap 5.3, Chart.js 4.4.6 y SweetAlert2. Diseño y diagramas: Mockflow y Lucidchart.

## Metodología
Scrum en siete sprints: mockups y prototipos, diseño y navegación, formulario y carga de datos, gráficos, pruebas y optimización, documentación, e implementación final y presentación.
